# README

Program needed for editing overlay (either one works fine):
- Notepad ++
- Visual Studio Code
  
You also need a Github account to host the schedule
## Changing the information

To change the top part above the schedule, open index.html and follow the comment instructions.
To change the content information, all you need to do is open the script.js with program of your choice.
There are comments there with what you can or can not touch.
Just follow those and you will be fine!

## Changing the style

To change the style it you can edit the root of the style.css file in the program of choice.
you can fiddle around with it, BUT beware that changing stuff outside of colors might break the whole design.
